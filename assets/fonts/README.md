# 设置页字体

`NotoSansSC-Regular.ttf` 是 Noto Sans SC 的真实 400 字重静态实例，采用
SIL Open Font License 1.1，完整许可见 `OFL-NotoSansSC.txt`。Reserved Font Name
为 `Source`，本实例不使用该保留名称。

该实例从本机已安装的 `NotoSansSC-VF.ttf` 的 `wght=400` 轴值生成；原字体版权
信息为 © 2014–2021 Adobe。字体通过 `include_bytes!` 内置，仅设置页使用，
无需用户安装字体；岛体沿用原有字体族。

- 上游项目：https://github.com/google/fonts/tree/main/ofl/notosanssc
- 生成工具：FontTools 4.68.0 `varLib.instancer.instantiateVariableFont`
- 静态实例 SHA-256：`72281A9E4EB41D9A28037A2262A3E100DEE942A728D5AC1A21018EEA181B300D`
